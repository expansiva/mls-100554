WidgetDefaultToolbarSocial

Barra de ícones sociais personalizável para integração rápida em qualquer projeto web

🔗 Exiba links para redes sociais de forma elegante, responsiva e acessível. Ideal para portais, dashboards, landing pages e apps que precisam destacar perfis sociais de maneira moderna e sem complicação.

Demonstração ao vivo
🛠️ Edite o JSON acima para testar diferentes plataformas, layouts e tamanhos!

Por que usar este componente?

  • ⚡ Integração instantânea via Web Component
  • 🎨 Layout horizontal ou vertical, escolha o que combina com seu design
  • 🔒 Acessível, seguro e responsivo por padrão
  • 🧩 Personalize plataformas, links e ícones facilmente via JSON
  • 🚀 Sem dependências externas e pronto para produção

Como usar?

<widget-default-toolbar-social-100554
  config='{"items":[{"platform":"twitter","href":"https://twitter.com/usuario"},{"platform":"github","href":"https://github.com/usuario"}],"layout":"horizontal","size":"md"}'
></widget-default-toolbar-social-100554>
Basta copiar e colar no seu HTML. Personalize as plataformas e links conforme sua necessidade!
