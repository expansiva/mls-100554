Widget Select One Scrollspy Single

Navegação lateral inteligente com auto-highlight e scroll suave

🔎 Selecione e navegue entre seções de forma fluida: este componente cria uma lista lateral de links que destaca automaticamente a seção visível conforme você rola a página. Ideal para documentações, dashboards e páginas longas!

Demonstração

Properties

Introdução

Este é um exemplo de seção. Ao rolar ou clicar, o item correspondente na lista lateral será destacado automaticamente.

Funcionalidades

  • Auto-highlight conforme a rolagem
  • Scroll suave ao clicar
  • Offset configurável para cabeçalhos fixos

Exemplo de Uso

Ideal para navegação em páginas longas, documentações técnicas ou qualquer interface que precise de navegação lateral dinâmica.

Principais Benefícios

  • ⚡ Navegação instantânea entre seções
  • 🖱️ Scroll suave e experiência moderna
  • 🎯 Destaque automático da seção visível (scrollspy)
  • 🔒 Acessível e personalizável
  • 🔧 Fácil integração em qualquer projeto web

Como usar 

				<widget-select-one-scrollspy-single-100554
  selectedvalue="section1"
  options='[{"label":"Introdução","value":"section1","anchor":"#section1"},{"label":"Funcionalidades","value":"section2","anchor":"#section2"}]'
  offset="56"
  label="Seções"
  hint="Escolha uma seção para navegar"
  ariaLabel="Lista de seções"
></widget-select-one-scrollspy-single-100554>

Integração e Casos de Uso

  • 📚 Documentações técnicas: navegação lateral para capítulos e tópicos.
  • 📊 Dashboards e relatórios: acesso rápido a diferentes painéis ou seções de dados.
  • 📝 Páginas longas: sumário interativo para facilitar a navegação do usuário.

💡 Integração: basta adicionar a tag do componente e configurar as opções conforme suas seções. O scrollspy funciona automaticamente!
