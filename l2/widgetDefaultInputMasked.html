widget-default-input-masked-100554

Campo de entrada de texto com máscara dinâmica, validação e UX aprimorada

O widget-default-input-masked-100554 é um WebComponent pronto para uso, que permite criar campos de texto com máscaras customizáveis, validação automática e feedback visual de erros. Ideal para formulários modernos que exigem precisão e experiência do usuário profissional.

Configure máscaras como CPF, CNPJ, datas, telefones e muito mais — sem dependências externas.

  • 🪄 Máscara dinâmica configurável para qualquer padrão
  • ⚡ Integração instantânea em qualquer projeto Web
  • 🌎 Suporte a múltiplos idiomas e mensagens customizáveis

Como usar

📋 <widget-default-input-masked-100554
  label="CPF"
  placeholder="Digite o CPF"
  hint="Somente números"
  name="cpf"
  mask="999.999.999-99"
  required="true"
  errormessage="CPF inválido"
  validationpattern="^\d{3}\.\d{3}\.\d{3}-\d{2}$"
  showerror="true"
></widget-default-input-masked-100554>

Basta inserir a tag acima no seu HTML e personalizar as propriedades conforme sua necessidade.
