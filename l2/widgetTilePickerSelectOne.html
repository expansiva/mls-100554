Widget Tile Picker Select One

Selecione visualmente uma opção com mini-cards de imagem + texto

O Tile Picker é um componente de seleção visual, ideal para permitir que usuários escolham temas, templates ou opções de forma intuitiva e moderna. Cada opção é apresentada como um mini-card com imagem e rótulo, tornando a escolha mais amigável e rápida.

Demonstração

Properties

Por que usar o Tile Picker?

  • 🎨 Visual e intuitivo: Permite escolhas rápidas e agradáveis, com imagens e rótulos claros.
  • ⚡ Integração instantânea: Pronto para uso em qualquer projeto web moderno, sem dependências externas.
  • 📱 Responsivo: Adapta o layout dos cards conforme o tamanho da tela, garantindo ótima experiência em desktop e mobile.
  • 🛡️ Acessível: Suporte a teclado e atributos ARIA para acessibilidade.
  • 🔧 Altamente configurável: Personalize rótulos, dicas, opções, grid e estados (disabled/read-only) facilmente.
