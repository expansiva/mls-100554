Por que usar este componente?

  • 🔎 Busca instantânea : Filtra opções conforme o usuário digita, mesmo em listas grandes.
  • ⚡ Performance : Suporte a carregamento remoto e feedback visual de loading.
  • 🦾 Acessibilidade : Totalmente navegável por teclado e com suporte a ARIA.
  • 🎨 Visual Material : Interface inspirada no Material UI, moderna e familiar.
  • 🔗 Fácil integração : Use em qualquer projeto Web, inclusive frameworks modernos.

Como usar

Copie e cole: 
				<widget-select-one-autocomplete-material-100554
  label="Escolha uma linguagem"
  hint="Digite para filtrar"
  options='["JavaScript","TypeScript","Python","Java","C#"]'
  required="false"
  disabled="false"
  loading="false"
  noResultsMessage="Nenhum resultado encontrado"
  ariaLabel="Campo de seleção de linguagem"
></widget-select-one-autocomplete-material-100554>
