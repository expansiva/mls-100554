Módulo L7 - Preview e Funcionalidades

Descrição

O módulo L7 é voltado para o usuário final ou cliente do projeto. Este módulo permite que o usuário visualize a página no formato de produção, insira comentários e sugestões, e acompanhe as versões e o histórico de alterações.

Funcionalidades

  1. Visualização da Página em Formato de Produção
    • Permite ao usuário ver a página como ela aparecerá após a publicação, sem a possibilidade de alterar o conteúdo.
  2. Inserir Comentários, Sugestões ou Solicitações
    • Oferece um espaço para que o usuário possa inserir comentários, sugestões ou solicitações para futuras implementações.
  3. Visualizar Versões e Histórico de Alterações
    • Permite ao usuário ver a versão atual da página, a versão em desenvolvimento e o histórico completo de alterações feitas.

Fluxo de Uso

  1. O usuário acessa o módulo L7 e visualiza a página no formato de produção para ter uma ideia clara de como ela ficará após a publicação.
  2. Utiliza o espaço dedicado para inserir comentários, sugestões ou solicitações que considera relevantes para o projeto.
  3. Acessa a seção que mostra as versões e o histórico de alterações para acompanhar o progresso e as modificações feitas na página.
  4. Acompanha o aplicativo na questão de Acessibilidade,ara garantir que o projeto seja acessível a todos os usuários, incluindo aqueles com deficiências.
O módulo L7 é crucial para garantir que o projeto atenda às necessidades e expectativas do usuário final. Ele oferece uma forma eficaz de coletar feedback direto do usuário, o que é vital para o sucesso de qualquer projeto.
