Widget Default Navigation Links

Navegação suave por seções — links âncora modernos para suas páginas

🔗 O Widget Default Navigation Links permite criar menus de navegação do tipo anchor para rolar suavemente até seções específicas da sua página. Ideal para landing pages, documentações, dashboards e qualquer aplicação SPA.
Simples, responsivo e pronto para integrar!

Demonstração ao vivo

Menu de navegação simples

Por que usar este componente?

  • ⚡ Scroll suave até seções, com offset configurável
  • 🧩 Fácil integração em qualquer SPA, dashboard ou landing page
  • 🎯 Sincronização automática com o scroll da página
  • 🎨 Personalizável: badges, labels, offset, itens dinâmicos
  • 🔒 Acessível e responsivo

Como usar?

📋 <widget-default-navigation-links-100554 config='{"recommendedWidget":"anchor","items":[{"label":"Seção 1","href":"#sec1"},{"label":"Seção 2","href":"#sec2"}],"scrollSync":true}'></widget-default-navigation-links-100554>

Basta passar a propriedade config com os itens desejados.
O componente cuida do scroll e seleção automaticamente.
