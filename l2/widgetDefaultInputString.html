Widget Default Input String

Campo de texto inteligente com contador de caracteres em tempo real

O Widget Default Input String é um campo de texto moderno, acessível e personalizável, ideal para formulários web que exigem controle preciso de entrada, validação e feedback instantâneo ao usuário.

Com suporte a contador de caracteres, validação de padrões, mensagens de erro e dicas, ele se adapta facilmente a qualquer fluxo de cadastro, login ou edição de dados.

Por que usar este componente?

  • 🔢 Contador de caracteres em tempo real, com feedback visual e acessível.
  • 🛡️ Validação nativa de mínimo e máximo de caracteres, além de suporte a regex (pattern).
  • 💬 Mensagens de erro e dicas customizáveis para melhor experiência do usuário.
  • 🔗 Fácil integração com sistemas de binding e gerenciamento de estado.
  • 🌐 Internacionalização automática (PT/EN) para contador e mensagens.
  • ⚡ Performance otimizada e pronto para uso em qualquer projeto web moderno.

Como usar?

<widget-default-input-string-100554
  label="Nome"
  hint="Digite seu nome completo"
  value="{{ui.form.nome}}"
  placeholder="Ex: Maria Silva"
  required="true"
  maxlength="40"
  minlength="5"
  errormessage="Preencha pelo menos 5 caracteres"
  pattern="[A-Za-z ]+"
></widget-default-input-string-100554>
