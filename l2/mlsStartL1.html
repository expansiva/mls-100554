Módulo L1 - Back-End: Descrição e Funcionalidades

Descrição

O módulo L1 é voltado para o programador back-end e foca na lógica do servidor, incluindo autoridades, regras de negócio e persistência de dados. Este módulo também é responsável por testar as rotinas em um ambiente de testes e gerenciar o layout das tabelas no banco de dados.
  1. Programar Rotinas no Servidor
    • API para Consultas Comuns: Desenvolvimento de APIs que serão utilizadas em várias páginas para consultas comuns.
    • Rotinas de Validação e Hidratação: Programação de rotinas que serão responsáveis pela validação da página e pela hidratação, ou seja, o envio de dados para a página após um post back.
  2. Testar em Ambiente de Testes
    • Ferramentas e processos para testar as rotinas programadas em um ambiente isolado antes de serem implementadas no ambiente de produção.
  3. Verificar e Implementar Layouts das Tabelas no Banco de Dados
    • Processos para verificar e implementar os layouts das tabelas no banco de dados, garantindo que os dados sejam armazenados de forma eficiente e segura.

Fluxo de Uso

  1. O usuário começa programando as rotinas que serão executadas no servidor, focando em autoridades, regras de negócio e persistência de dados.
  2. Desenvolve APIs para consultas comuns que serão usadas em várias páginas do projeto.
  3. Programa rotinas específicas para validação e hidratação de páginas.
  4. Testa todas as rotinas em um ambiente de testes para garantir que funcionem como esperado.
  5. Verifica e implementa os layouts das tabelas no banco de dados para garantir a eficiência e segurança no armazenamento de dados.
O módulo L1 é fundamental para o funcionamento correto e seguro do projeto. Ele garante que todas as regras de negócio sejam implementadas corretamente e que os dados sejam armazenados de forma segura e eficiente.
