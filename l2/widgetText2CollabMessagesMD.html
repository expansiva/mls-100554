widget-text2-collab-messages-md

Transforme mensagens Markdown Slack-style em HTML seguro e bonito, pronto para colaboração.

O widget-text2-collab-messages-m-d-100554 converte textos em Markdown no estilo Slack (com menções, canais, comandos, listas, links e muito mais) em HTML seguro e estilizado, ideal para chats, feeds colaborativos e integrações modernas.

Perfeito para exibir mensagens de usuários, bots ou sistemas, mantendo o visual limpo e seguro.

Por que usar este componente?

  • 🔒 Seguro por padrão: Sanitiza o HTML e evita XSS automaticamente.
  • ✨ Visual moderno: Renderiza menções, canais, comandos, listas, links e blocos de código com destaque visual.
  • ⚡ Pronto para colaboração: Ideal para chats, feeds, bots e integrações em tempo real.
  • 🛠️ Fácil integração: Use como qualquer WebComponent, sem dependências extras.
  • 🧩 Customizável: Controle o texto dinamicamente via state ou props.

Como usar

📋 <widget-text2-collab-messages-m-d-100554-100554
  text="Olá **mundo**! Veja o canal #geral, fale com @lucas ou use /ajuda."

Exemplos de integração

💬 Chat colaborativo: Exiba mensagens de usuários com menções, canais e comandos destacados.
🤖 Respostas de bots: Formate respostas automáticas com links, listas e blocos de código.
📢 Feeds e notificações: Destaque comandos, canais e menções em painéis de atividades.
🔗 Documentação interativa: Permita que usuários insiram exemplos de código e links facilmente.

Basta passar o texto em Markdown Slack-style na propriedade text .
