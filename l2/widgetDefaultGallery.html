Widget Default Gallery 🖼️
Galeria de imagens simples, elegante e fácil de integrar
Exiba imagens de forma profissional em qualquer aplicação web. O Widget Default Gallery permite navegar entre imagens com botões intuitivos, mostrando o nome do arquivo e suporte a teclado. Ideal para dashboards, portais, e sistemas internos.
Demonstração ao vivo
Principais vantagens
  • ⚡ Integração instantânea via Web Component
  • 🖱️ Navegação fácil por botões ou teclado
  • 🔤 Exibe o nome do arquivo da imagem
  • 🌐 Suporte multilíngue automático (PT/EN)
  • 🎨 Visual limpo, responsivo e personalizável
  • 🔒 Sem dependências externas

Exemplos de integração
📁
Portais internos: Mostre imagens de produtos, documentos ou banners em sistemas corporativos.
🛠️
Dashboards customizados: Incorpore a galeria em painéis de controle para visualização rápida de imagens.
🌍
Sites multilíngues: O widget detecta o idioma do navegador e ajusta automaticamente os textos.
🔗
Integração via JSON: Controle as imagens e navegação dinamicamente usando states ou APIs.
