Widget Default Text

Exiba textos dinâmicos, banners ou citações com flexibilidade e acessibilidade

📝 O Widget Default Text permite exibir textos simples, banners informativos ou citações estilizadas em qualquer aplicação web. Personalize o conteúdo, o estilo e até links de forma declarativa, com suporte a acessibilidade e integração fácil via propriedades.

Demonstração ao vivo

Por que usar o Widget Default Text?

  • ⚡ Versátil: Exiba textos, banners, citações ou links com uma única tag.
  • 🔗 Fácil integração: Use propriedades simples para personalizar conteúdo e comportamento.
  • 🦾 Acessível: Suporte a citações, links e multiline, com markup semântico.
  • 🎨 Personalizável: Controle o tipo de exibição via JSON (text, quote, banner, link, etc).
  • 🔒 Seguro: Links abrem em nova aba e com rel="noopener noreferrer".

Como usar

<widget-default-text-100554 text="Olá mundo!" config='{"type":"text"}'></widget-default-text-100554>
💡 Basta alterar text e config para personalizar.

Onde aplicar?

  • 📢 Banners informativos em dashboards ou portais.
  • 💬 Citações de clientes, depoimentos ou frases de destaque.
  • 🔗 Links contextuais ou chamadas para ação.
  • 🧩 Mensagens dinâmicas em formulários, listas ou cards.
🔧 Integre facilmente em qualquer projeto web ou framework que suporte Web Components.
